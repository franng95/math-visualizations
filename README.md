# Math Visualizations – Linear Algebra Transformations

Year 2 maths coursework visualizing 3D linear algebra transformations using Python.

## What it does

- `scaling_visualization.py` — plots a 3D triangle before and after a scaling transformation (4× in x, 3× in y), showing the effect on vertex coordinates
- `rotating_visualization.py` — plots a 3D object before and after a rotation transformation

Output PNGs are included (`scaling_O1.png`, `rotation_O2.png`).

## Running

```bash
pip install matplotlib numpy
python scaling_visualization.py
python rotating_visualization.py
```

## Tech

Python · NumPy · Matplotlib · 3D plotting · Linear algebra
